# Captures de l'interface

- `reference/` : état de référence de l'interface (en, fr, de, ar, ja — 1280 × 760), produit par
  `python scripts/capture_ui.py <langue> docs/captures/reference/<langue>.png 1280 760`.
- `<branche>/` : captures jointes à une PR par l'agent `designer-interface`.

Les scènes affichées sont factices (dossier temporaire) : aucune donnée réelle.
